# Pratheek Janadri — Personal Portfolio

A cinematic, responsive React portfolio built with Vite. The experience uses a dark navy / electric-blue visual system, animated loading screen, scroll reveals, responsive navigation, interactive skill filters, certificate detail cards, project concepts and a browser-local media manager.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
npm run preview
```

## Personalise the site

- Edit `src/data.js` to update profile details, social URLs, skill states, credentials and project content.
- Use **Edit media** in the navigation or footer to add the hero portrait and original certificate images.
- Media added through the dashboard is stored in the current browser's local storage only. It is a local preview tool, not a server upload or a GitHub asset upload.
- Replace the concept project artwork or add verified project URLs when those projects are ready to share.

## Accuracy notes

The site intentionally avoids invented graduation dates, marks, CGPA, certificate IDs, proficiency percentages, email addresses and social links. Virtual job simulations are labelled as simulations rather than employment or internships.
